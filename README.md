# QA Regression Automation

## Project Overview

Automated regression testing using Playwright
and GitHub Actions.

## Technologies

- JavaScript
- Playwright
- GitHub Actions
- Node.js
- HTML Reporting

## Application Under Test

https://www.saucedemo.com/

## Execution

Tests execute through GitHub Actions.

Triggers:
- Manual workflow execution
- Push to main
- Pull requests to main

## Reports

HTML reports and test evidence are
uploaded as GitHub Actions artifacts.
